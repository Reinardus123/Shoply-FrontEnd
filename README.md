# 🛒 Shoply Frontend

Frontend for Shoply, a full-stack e-commerce web application built with React and Tailwind CSS.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Axios
- React Router
- SweetAlert2

## Features

- Authentication
- Product Browsing
- Categories
- Product Detail
- Product Variants
- Shopping Cart
- Wishlist
- Checkout
- Order History
- Admin Dashboard

## Installation

```bash
npm install
npm run dev
